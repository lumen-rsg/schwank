# schwank 1.0.0

The first stable schwank release is a private, local-first home hub built for a
shared apartment. One Orange Pi owns the data and serves browsers plus native
desktop clients; no OpenAI-hosted deployment or third-party database is
required.

## What is included

- Private and explicitly shared nutrition, calorie, macro, hydration,
  medication, reminder, task, spending, recurring payment, and organiser data.
- Shared pantry batches, recipes, a six-course weekly meal planner, combined
  shopping lists, household chat, habit-reduction heatmaps, and wishlist voting.
- Nutrition targets and optional DeepSeek-powered menu proposals using only the
  data each person permits for that request.
- English and Russian interfaces, household and avatar images, account export,
  controlled enrollment, session management, ownership transfer, and complete
  account deletion.
- Native notifications and background tray operation in the Electron clients,
  with bilingual first-run and offline recovery screens.

## Downloads

- macOS: Apple Silicon DMG or ZIP.
- Linux: x86-64 AppImage.
- Windows: x86-64 NSIS installer.

These household-test installers are not code-signed. The operating system may
ask for an extra confirmation before opening them. Every desktop client still
requires access to the Schwank server on the home network.

## Operations and privacy

The Fedora-family Orange Pi profile includes migration-aware health checks,
bounded privacy-safe logs, encrypted daily SQLite backups, an off-board restore
drill, and guarded rollback. The server enforces authorization independently of
the interface: private records are never returned to housemates, while
deliberately shared household resources remain collaborative.

Before upgrading an existing board, create and verify an encrypted backup and
follow the staged procedure in `deploy/fedora/README.md`.
